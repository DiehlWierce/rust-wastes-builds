## Как запустить

- **Windows:** распакуй и запусти `RustWastes.exe`. Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
- **macOS:** распакуй и запусти «Ржавая Пустошь». В первый раз: правый клик → «Открыть» → «Открыть» (macOS 15 — «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть»). Если пишет, что приложение «повреждено»: `xattr -cr "/путь/к/Ржавая Пустошь.app"`.
- **Приставки:** распакуй `…-PortMaster.zip` в папку `ports` на карте памяти — появится «Rust Wastes». Игра сама включит полный экран, подписи кнопками геймпада и экономный режим. Выход — Select + Start. Если что-то не так, смотри `ports/rustwastes/log.txt`.

Режимы новой игры: «Обучение» (первые шаги по порядку), «Кампания» («Тринадцатый» — расследования ведут к Пастуху), «Свободная игра» (без наставлений). Сохранения прошлых сборок не подходят.

## Что в игре

- **Живой мир.** Банды, караваны, звери и города воюют, торгуют и идут набегом сами по себе, пока ты занят своим.
- **Ты — никто.** Старт без оружия: гайки и рваньё. Кузнец, торговец, наёмник, вождь — путь выбираешь сам.
- **Бой с ранами по частям тела.** Серии ударов, блок и парирование, рывок, арбалеты, протезы вместо потерянных рук и ног.
- **Города со своими фишками.** Горн куёт шедевры на заказ, Соляной Рынок — аукцион, Кряж — лестница чемпионов, Твердыня Ордена — архив Древних.
- **Свой лагерь.** Кузнец, бронник, портной и протезист работают на склад, караваны возят товар по городам.
- **Спутники.** Нанимай людей с именем и историей, учи стойкам (напор, осторожно, охрана) — они дерутся, как ты.
- **Колоссы и подземелья.** Руины Древних с ловушками, дронами и сейфами; пять уровней под Сорокалетним Холмом.
- **Ночь, бури, звери.** Смена дня и ночи, пыльные бури, ездовые звери (H), календарь с рынками и праздниками.
- **Геймпад и приставки.** Всё управляется с геймпада, подсказки кнопок — в каждом окне.

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Идти | WASD / стрелки | крестовина или стик |
| Удар | J / левая кнопка мыши | X |
| Блок | K / правая кнопка мыши | R1 |
| Рывок | Пробел | B |
| Действие | E | A |
| Вещи | I | Y |
| Персонаж | C | Select |
| Карта | Tab / M | L1 |
| Журнал заданий | L | — |
| Приказ отряду | Q | R2 |
| Сдаться | G | L2 |
| Зверь: сесть, слезть, свистнуть | H | L3 |
| Красться | Ctrl / V | R3 |
| Закрыть окно, меню | Esc | Start (B — назад) |

В окнах с вещами: левая кнопка мыши берёт вещь в руку, правая — быстрое действие (надеть, съесть, купить), Shift — часть стопки. На геймпаде A над вещью открывает меню действий; внизу каждого окна строка подсказок.
